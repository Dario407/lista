# DALLA NOSTRA PARTE · ISIS Carducci-Dante Trieste

Portale mobile-first e sistema di reindirizzamento QR code per il Comitato Studentesco e la lista **DALLA NOSTRA PARTE** (Candidato: Dario Nitu).

## Scorciatoie QR Code
- / o /qr → Apre l'hub mobile-first (Instagram + Cantiere Aperto + Modulo Segnalazioni)
- /ig o ?to=ig → Reindirizza direttamente al profilo Instagram ufficiale
- /segnala o ?to=segnala → Porta direttamente allo sportello segnalazioni
